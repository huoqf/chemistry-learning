### 2.2 内容问题清单

#### 🔴 C1 — 严重：有机机理页给出错误的"反马氏加成"结论

**位置**：`src/features/organic/mechanism/constants.ts:263`

> 原文：`note: '遵循马氏规则，若在过氧化物催化下则发生反马氏加成生成 1-氯丙烷。'`

**问题**：**过氧化物效应（反马氏自由基加成）只适用于 HBr**，HCl、HI 均不发生。本页语境是 `CH₃-CH=CH₂ + HCl`，却告诉学生"过氧化物下生成 1-氯丙烷"——这是明确错误的结论，且属于选必三高频易错点。

同一错误在文件内多处泛化（把"卤化氢"整体说成可反马氏）：`:104`（`'过氧化物存在：自由基机理，Br 加在含 H 多的双键碳上 (反马氏)'`）、`:454`、`:517`。

**建议**：改为"HBr 在过氧化物存在下发生反马氏加成；HCl 无此效应"，并在 `:104/:454/:517` 明确限定为 HBr。

#### 🟠 C2 — 中等：亚硝酸根现象写成"淡蓝色"，与本项目自定规范冲突

**位置**：`src/features/inorganic-ion-matrix/data/conflicts/mainGroupConflicts.ts:140`

> 原文：`phenomenon: '溶液呈淡蓝色，管口产生红棕色气体。'`

**问题**：NaNO₂ / HNO₂ 溶液为无色（浓时微黄），绝无"淡蓝色"。更严重的是，项目自己的规范（`GAOKAO_CHEMISTRY_RULES.md` 三、"严禁将 NO₂⁻ 酸化误写为'溶液显淡蓝色'"）和守护测试（`inorganicChemistryTruthAuditor.test.ts:88`）**都明确禁止**这一表述——只是守护测试查的是 `ION_DATA`，没查共存矩阵，于是漏网。

**建议**：改为"溶液无色，加稀酸后逸出无色 NO，管口遇空气变红棕色 NO₂"；并将该字段纳入审计范围。

#### 🟠 C3 — 中等：Al³⁺ / Mg²⁺ 沉淀先后顺序答案键错误（同页自相矛盾）

**位置**：`src/data/quiz/model-reagent-step.ts:63`

> 原文：`{ label: 'A', text: '滴加 NaOH 过程中，Al³⁺ 比 Mg²⁺ 先沉淀', isCorrect: false }`

**问题**：`Ksp[Al(OH)₃] ≈ 1×10⁻³³` 远小于 `Ksp[Mg(OH)₂] ≈ 5.6×10⁻¹²`，Al³⁺ 在 pH≈3.3 即开始沉淀，Mg²⁺ 需 pH≈9.4 —— **Al³⁺ 确实比 Mg²⁺ 先沉淀**。同文件 `:144/:148` 的 var-reagent-5 正解正是 `Fe³⁺ ➔ Al³⁺ ➔ Mg²⁺`。两题结论互斥，且若 A 为真则本题出现两个正确项。

**建议**：改写选项 A 为真正错误的陈述（如"两者同时开始沉淀"），或调整本题答案键。

#### 🟠 C4 — 中等：工业流程 ni-co-li 工序二，H₂O₂ 的角色自相矛盾

**位置**：`src/features/industrial-flow/hooks/useIndustrialFlowChemistry.ts:657` 与 `:668`

> `coreReaction`（默认分支）：`'2Fe²⁺ + H₂O₂ + 2H⁺ = 2Fe³⁺ + 2H₂O'`（H₂O₂ 作**氧化剂**）
> `scoringAnswer`（ni-co-li 分支）：`'H₂O₂ 在此反应中作还原剂，将难溶的 +3 价钴还原为可溶的 +2 价 Co²⁺ 溶出。'`

**问题**：同一体系同一工序，一处称氧化剂、一处称还原剂；且 ni-co-li 体系杂质离子为 Fe³⁺/Al³⁺（`:113`），本无 Fe²⁺，套用 Fe²⁺ 氧化方程式不当。

**建议**：为 ni-co-li 单独写 `coreReaction` 与 `coreQuestion`，聚焦 Co(III)→Co(II) 还原溶出与 Fe³⁺/Al³⁺ 除杂。

#### 🟠 C5 — 中等：乙炔收集方法与自述密度自相矛盾

**位置**：`src/features/gas-chain/data/gasMatrixItems.ts:216-217`

> `collectionMethod: '排水集气法 或 向上排空气法'`
> `collectionReason: '微溶于水；密度 (M=26) 略小于空气'`

**问题**："向上排空气法"适用于**比空气重**的气体；同一处紧邻的理由自身就写"密度略小于空气"。乙炔标准做法为**排水法**（教材：难溶于水）。

**建议**：`collectionMethod` 改为"排水集气法"，理由处注明密度略小于空气不宜排空气收集。

#### 🟠 C6 — 中等：NH₃ 收集"浸稀硫酸的棉花"两处结论相反

**位置 A**：`src/features/gas-chain/data/gasMatrixItems.ts:84`

**位置 B**：`src/data/quiz/model-gas-chain.ts:121` 与 `:130`

#### 🟠 C7 — 中等：勒夏特列平衡浓度模型违反 N 原子守恒

**位置**：`src/data/quantities/reaction-principle/leChatelier.ts:16`、`src/features/reaction-principle/le-chatelier/hooks/useLeChatelierChemistry.ts:66-73`

模型设定：
```
totalEquiv = (1.5 + addedNO2) * pressure      // 求解式：K·x² + x - totalEquiv = 0
initNO2 = (1.0 + addedNO2) * pressure
initN2O4 = 0.5 * pressure
```

**问题**：N₂O₄ 含 **2** 个 N，正确物料关系为 `c(NO₂) + 2·c(N₂O₄) = 总N`；初态总 N 当量 = `(1.0+added) + 2×0.5 = 2.0 + added`，但求解用 `1.5 + added`（相当于把 N₂O₄ 按 1 个 N 计）。结果平衡态 N 当量变为 `2.35 + added > 2.0 + added`，**N 原子凭空增加**。

默认参数下平衡浓度约为 c(NO₂)≈0.65、c(N₂O₄)≈0.85（按守恒应约 0.59 / 0.70）。

**影响范围**：平衡**移动方向**判定仍正确（这是教学重点），但"守恒量"演示错误——对"化学反应原理"教学而言仍是需要修正的硬伤。

**建议**：物料关系改为 `2K·x² + x - 总N = 0`，总 N 基数取 `2.0 + addedNO2`（压力项分别作用于各浓度初值）。

#### 🟠 C8 — 中等：大学有机内容标记为"高考冲刺"

**位置**：`src/features/organic-retrosynthesis/data/protectionStrategyModels.ts:282`（`difficulty: '高考冲刺'`）等

**问题**：该模块使用 LiAlH₄ 强还原（`:284`）、Diels-Alder [4+2] 环加成与乙二醇环状缩醛保护（`:274-307`）、Zn 粉脱溴复原双键、DCC/SOCl₂ 偶联、"合成子 synthon"/FGI 等术语。上述均**超出人教版选择性必修3 主线**，但被标注为"高考冲刺"，容易让学生误判为必考内容（贝诺酯本身是高考常见素材，但环状缩醛保护在教材中仅属拓展层面）。

**建议**：`difficulty` 改为"大学/竞赛拓展"或"信息题素材"，并在模块开篇显著提示超纲。（**注**：Diels-Alder 是否进入教材拓展，建议按三版教材交集再确认。）

## 五、总体评价

**做得好的地方**（值得保留）：

- 架构门禁成体系且**实测全绿**：字号、rAF、marker、WebGL context、文件规模五道闸门都带明确"为什么"，`check-no-marker.mjs` 还带白名单到期提醒，工程素养高于一般项目。（**注意**：CI 中的 oxlint 零警告门禁不属这五道闸门，当前处于失败状态，见 G3b。）
