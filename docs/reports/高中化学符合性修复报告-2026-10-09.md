### 附带修掉的一处**本轮自身引入**的回归

P1-M2/M3 的 `NH₃·H₂O` 改写中，6 处写成了 `\cdot`（单反斜杠）。JS 字符串里 `\c` 会**丢掉反斜杠**，KaTeX 实际收到 `cdot`，公式静默损坏；且与同一字符串内已正确的 `\\cdot` 自相矛盾。

- 该问题被 `oxlint --max-warnings 0` 门禁捕获（`no-useless-escape`，6 条），已全部修正为 `\\cdot`。
- 另做了一次专项扫描，排查 `\r`/`\t`/`\n` 这类**合法转义**（oxlint 不会报）是否也污染了 LaTeX 命令（如 `\rightleftharpoons`→回车符）：**未发现残留**。

### 7.3 母题五 σ/π 口径的根治（NEW-3）

**原缺陷**：SO₂ / SO₃ 逐键 `bondOrder: 2`（键级和 4 / 6）却 `piBonds: 1`；CO₃²⁻ / NO₃⁻ 逐键 `bondOrder: 1`（键级和 3）却也 `piBonds: 1`。两套口径**不可能同时为整数**，因此"逐键改成双键"这条路走不通。

**处置**：把 `bondOrder` 明确为**平均键级 = (σ 键数 + π 键数) / 边数**，据此填值——

- SO₂：2σ + 1 个 Π³₄ ⇒ 每键 **1.5**
- SO₃ / CO₃²⁻ / NO₃⁻：3σ + 1 个 Π⁴₆ ⇒ 每键 **4/3**
- CO₂：两个定域 C=O 双键 ⇒ 每键 **2**（不变）

于是得到**可机检的强不变式**：`Σ bondOrder = sigmaBonds + piBonds`，且 `bonds.length = sigmaBonds = bondPairs`——17/17 全部成立，已写入测试。同时删除恒为 `'sigma'`、与"1.33 键级"语义冲突且无消费点的 `bondType` 字段；口径与不变式写入 `types.ts` 的 `BondEdge` 文档与 `vseprData.ts` 文件头。

**已核实无行为影响**：`MoleculeMesh` / `HybridOrbitalMesh` 只读 `bond.id / fromAtomId / toAtomId`，渲染的是 σ 骨架单圆柱（本就与 `sigmaBonds` 一致），故不存在"3D 画双键、右屏按离域口径计数"的屏上打架。`bondOrder` / `bondType` 此前是**死数据**，本次是"消除矛盾口径"，不改任何渲染结果。
