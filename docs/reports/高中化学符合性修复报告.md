### C7 — 勒夏特列平衡模型违反 N 原子守恒 · ✅ 已修复
**文件**：`src/data/quantities/reaction-principle/leChatelier.ts:17-18`
- 原：`totalEquiv = (1.5 + addedNO2) * pressure`，求解式 `K·x² + x − totalEquiv = 0`（把 N₂O₄ 按 1 个 N 计 → 平衡态 N 凭空增加）
- 改：`const totalN = (2.0 + addedNO2) * pressure`，注释明确 `// 代入 c(N₂O₄) = K·c(NO₂)²，得 2K·c(NO₂)² + c(NO₂) − totalN = 0`

**化学依据**：N₂O₄ 含 2 个 N，物料关系应为 `c(NO₂) + 2·c(N₂O₄) = 总N`；初态总 N 当量 `(1.0+added) + 2×0.5 = 2.0+added` 现与求解式一致，N 原子守恒恢复。

## 七、关键工程结论（本次修复中形成，供后续维护参考）

### 7.1 **prettier 不能作为本项目的格式门禁**（重要纠正）
实测 `npx prettier --check "src/**/*.{ts,tsx}"`：
- `semi: true`（`.prettierrc` 原值）→ **634 个文件不通过**
- `semi: false` → **仍有 543 个文件不通过**

残余差异主因：prettier 会打散本项目**刻意保留的对象字面量列对齐**（如 `sm:    '4px'`）与注释列对齐。结论：**全量 `--write` 会破坏可读性，不可作为门禁**。故改为"机械可判规则"门禁（行尾空白 / 末尾换行 / 换行符混用），既堵住真实漂移，又不产生 500+ 文件的噪声 diff。策略已写入 `FORMATTING_POLICY.md`。

### 7.2 `check-large-files.mjs` 存在 off-by-one（顺带修复的真实 bug）
原实现 `text.split(/\r?\n/).length` 对**以换行结尾**的文件会多算 1 行。`useIndustrialFlowChemistry.ts` 内容恰为 800 行，却被报为 801 行而**误卡门禁**。修复：先剥末尾换行再切分，使阈值语义与"文件有多少行内容"一致。该文件由红转绿。

### 7.3 多源同构数据必须三处同步
同分异构体数据存在 **3 份**，改一处须同步三处顺序，否则左屏 / 右屏 / 渲染层不一致：
1. `src/data/isomerData.ts` —— 渲染用节点数据
2. `src/data/quantities/structure/isomerism.ts` —— 右屏 `ISOMER_DATA_SUMMARY`
3. `src/data/registries/structure.ts` —— 左屏 `controlMeta[].options`（**按 index 对应**）

C11 / C12 已严格按此三处同步。

### 7.4 E2E 不能 import `@/` 或 React 组件注册表
Playwright 用例由 **esbuild 直转**，不做 Vite/TS 别名解析。因此 G5 的动态路由列表**不能**直接 `import { gaokaoModels } from '@/data/gaokaoModels'`。解法：新增无依赖的 `e2ePageCatalog.ts`，再用单测 `e2ePageCatalog.test.ts` 断言它与真实注册表逐条一致，把"漂移"从运行时搬到单测层。

### 7.5 白名单机制应统一为"带 reason + targetDate"
项目原有 `check-no-marker.mjs` 已要求白名单条目带 `reason` + `targetDate`。本次把守恒扫描的**静默跳过**（G8）与新增代码风格门禁（G10）都统一到这一范式，避免"无原因、无到期日"的黑洞式豁免。

### 7.6 门禁的价值在"常绿"
审查报告 G3b 的判断被本次实测印证：**一处长期常红的门禁比没有门禁更糟**——它会训练所有人忽略 CI 信号。oxlint 现已清零，CI 六道门禁全绿，信号恢复可信。

### 7.7 环境约束（本机）
本机 **Bash 工具不可用**（PortableGit shim 缺 `dirname`/`ls` 等，`exit 127`），须改用 PowerShell；且 **PowerShell stdout 被吞**，须"写文件 + 读取文件"取结果。构建 / 删除文件需在关闭沙箱隔离的前提下执行（否则 `EPERM: dist\assets`）。这些不影响仓库产物，仅影响本机验证操作方式。
