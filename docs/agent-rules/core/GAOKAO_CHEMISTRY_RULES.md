# 高中化学与新高考命题合规性守门铁律（GAOKAO_CHEMISTRY_RULES）

> 本规范是化学学习系统针对“高中化学知识严谨性、新高考命题一致性、实验大题规范性”的核心守则。任何涉及化学数据、实验现象、方程式、共存矩阵的代码与内容必须 100% 遵守。

---

## 一、 教材基准与知识边界铁律

1. **三版教材交集基准**：
   - 基础知识严格以现行高中化学教材（人教版、鲁科版、苏教版）必修一/二及选择性必修一/二/三为基准。
   - **册名口径声明**：全项目（含 `src/data/knowledge/*.ts` 的 `chapter` 字段）统一使用**册（模块）级**简称——`必修一`/`必修二`/`选择性必修一`/`选择性必修二`/`选择性必修三`，**不等于某一具体"章"**。以人教版（2019）为例的锚点：必修第一册第四章=化学键（物质结构 元素周期律），必修第二册第五章=硫/氮/硅（化工生产中的重要非金属元素）。
2. **严禁大学知识与特异试剂超纲下渗**：
   - 严禁将大学分析化学的专用试剂（如铋酸钠 $\text{NaBiO}_3$、丁二酮肟 $\text{DMG}$、四苯硼钠、铝试剂、格氏试剂 $\text{RMgX}$ 等）作为常规离子的基础检验或合成路线的**必选答案**；
   - **三层归属口径（取代笼统的"超纲"标签）**：凡涉及教材边界之外的内容，必须按下列三层显式标注，禁止一句"超纲/拓展"打包：
     1. `【教材主线】`——现行人教版必修/选择性必修正文要求（如选必3 §3.5 的逆合成分析法、常见官能团保护、羟醛缩合、Diels-Alder），属**必学必考**；
     2. `【信息题素材】`——教材未作要求，但高考常以"给出信息"的方式考查（如格氏试剂、$\text{NaBiO}_3$、丁二酮肟、$\text{LiAlH}_4$、Zn/EtOH 脱溴）；
     3. `【超纲】`——大学有机合成学派表述（如"合成子 synthon"、"FGI"），高考至多作背景名词出现，**不作考点**。
   - 历史写法 `【信息题拓展】`/`【工业流程拓展】` 与 `【信息题素材】` 同义；新代码统一使用 `【信息题素材】`。
   - 有机合成模块的数据侧对应 `syllabusTiers`（见 `src/features/organic-retrosynthesis/types.ts`），左屏据此逐层提示。
3. **溶解性口径统一**：
   - 沉淀判断严格依据教材附录《常见酸、碱、盐的溶解性表（$20^\circ\text{C}$）》；
   - 微溶物（$\text{CaSO}_4$、$\text{Ag}_2\text{SO}_4$、$\text{MgCO}_3$、$\text{Ca(OH)}_2$）在“大量共存”题中一律判定为**互斥**；
   - 对于教材附录未列出但大学难溶的物质（如 $\text{Ca(AlO}_2)_2$），必须在解题说明中提示**“高考命题回避该争议，实战应采用选项排除法”**。

## 二、 离子方程式与化学反应书写铁律

1. **弱电解质与溶液试剂书写规范**：
   - 水溶液中加氨水，反应物必须书写为一水合氨分子 $\text{NH}_3\cdot\text{H}_2\text{O}$，严禁写作未电离的气态 $\text{NH}_3$ 且两边必须物料守恒；
   - 示例：$\text{AgCl} + 2\text{NH}_3\cdot\text{H}_2\text{O} = [\text{Ag}(\text{NH}_3)_2]^+ + \text{Cl}^- + 2\text{H}_2\text{O}$。
2. **可逆号 $\rightleftharpoons$ 与等号 $=$ 的严密适用**：
   - 人教版选择性必修1中明确具有平衡移动教学属性的可逆配合反应（如 $\text{Fe}^{3+} + 3\text{SCN}^- \rightleftharpoons \text{Fe(SCN)}_3$）必须保留可逆符号 $\rightleftharpoons$；
   - 弱电解质电离与盐类水解反应必须使用 $\rightleftharpoons$；普通复分解与彻底双水解反应使用 $=$。
3. **沉淀与气体符号完整性**：
   - 溶液体系中生成的难溶物必须标注 $\downarrow$，挥发性气体必须标注 $\uparrow$；
   - 歧化反应（如 $\text{S}_2\text{O}_3^{2-} + 2\text{H}^+ = \text{S}\downarrow + \text{SO}_2\uparrow + \text{H}_2\text{O}$）必须双符号齐全。

## 三、 高考实验大题“四步标准化模板”

所有离子的 `standardProcedure`（标准答题规范）必须完整包含高考阅卷四大核心采分点：
```
1. [取样] 取少量待测液于试管中
2. [操作] 滴加/加入 XX 试剂（必要时微热/振荡）
3. [现象] 若观察到/产生/出现 XX 特征现象（颜色改变、沉淀生成及颜色、特征气味、无色气体在管口变红棕）
4. [结论] 则证明原溶液中含有 XX 离子
```
- **禁止词汇**：严禁出现主观情绪词（如“非常漂亮的天蓝色”）或超纲实验微细现象（如将 $\text{NO}_2^-$ 酸化误写为“溶液显淡蓝色”）。

## 四、 自动化测试守护（CI 门禁）

在提交任何无机化学数据变更前，必须运行高考真理守门测试套件（命令与 `package.json` 口径统一，跨机器可移植）：

```bash
# 全量单测（推荐，CI 同款）
npm run test:run

# 只跑无机离子守门套件（按文件路径过滤，替换 <path> 为测试文件路径）
npx vitest run <path-to-*.test.ts>
```

所有测试项（试剂特异性、方程式守恒、大题四步答题模板、共存矩阵属性分类）必须 100% 保持绿色通过。
